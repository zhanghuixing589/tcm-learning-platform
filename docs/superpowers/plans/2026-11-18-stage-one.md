# 第一阶段工程与身份权限 Implementation Plan

**Goal:** 交付三端可运行工程以及注册、登录、刷新、注销、个人资料、角色和贡献资格申请闭环。

**Architecture:** 遵循已确认 Vue → Java → FastAPI 架构；Java 独占正式 MySQL 写入，身份领域按 api/application/domain/infrastructure 分层。现有 V1/V2 不修改。

**Tech Stack:** Java17、Spring Boot3.5.16、MyBatis-Plus、Flyway、Spring Security JWT；Vue3、Vite、TypeScript、Pinia、Axios、Element Plus；Python3.11、FastAPI。

本轮直接在授权目录顺序执行，不委派代理，不提交上级仓库其他项目。

## Task 1：Java 配置与集成用例

- [ ] 新建 `backend/pom.xml`、`application.yml`，锁定依赖。
- [ ] 新建 `backend/src/test/java/cn/tcm/platform/IdentityIntegrationTest.java`：空库迁移后 HTTP 注册登录、默认角色、401/403、资料归属、刷新重放与注销、禁用撤权、资格申请审批、角色授权。
- [ ] 执行测试观察缺少应用实现的失败，再实现入口、通用响应与过滤器、身份 Mapper/Service/Controller。
- [ ] 在隔离 MySQL 中重复运行，断言完整 Flyway V1/V2 生效。

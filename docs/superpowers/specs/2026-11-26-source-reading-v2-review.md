## 变更对照

| 评审项 | 第一版 | 第二版增量修订 |
|---|---|---|
| 格式 | EPUB/PDF/DOCX/TXT | 明确增加DOC；二进制识别与隔离转换，原件/衍生件独立 |
| 阅读路径 | 主要依靠统一结构化转换 | 保留安全AST，增加STRUCTURED/FIXED_LAYOUT/PLAIN_TEXT/ORIGINAL_PREVIEW，按真实产物与当前用户能力选择 |
| 复杂排版 | 不复刻任意CSS，复杂关联未展开 | 明确竖排/双行注释、脚注、多栏、图注、合并表格、固定版式和无目录；不可靠顺序不用于精确引用 |
| 文档能力 | 只列基本read/extract/download | 增加layoutMode、availableReadingModes、目录/图片/表格/脚注、文字选择/搜索/精确引用/字号能力；当前单元另有有效能力 |
| 解析结果 | 阅读结构全部就绪才可用 | 执行状态与内容结果分离，增加PARTIAL_SUCCESS、分阶段/单元覆盖和警告；安全阻断仍不能放行 |
| 来源审核 | 最新解析成功且阅读READY | 按安全可用模式、可靠引用范围和完整性审核；部分缺失需审核确认；预览型REFERENCE_ONLY单列待确认 |
| 扫描PDF | 沿现有文本层白名单 | 规划安全预览，无OCR时关闭文字能力与RAG；不能以存储成功伪报预览可用 |
| 媒体 | 主要PNG/JPEG，其他提示不支持 | GIF首帧/WebP校验或转换、SVG隔离栅格化、BMP/TIFF按需转换，保留图注/位置/帧覆盖和占位 |
| 数据单元 | source_reading_chapters兼任章和页 | 改为source_reading_units，CHAPTER/PAGE/TEXT_SECTION；可选目录节点独立于正文顺序 |
| 版本/产物 | 阅读版关联一次parseRun | 加独立readingVersionNo、衍生文件hash链、处理覆盖和模式；预览版可无文字批次；部分版补齐要新快照 |
| 整理交互 | 整理/复制后打开侧栏 | 默认纯阅读；选文可新建、加入当前/其他本人草稿、保存个人摘录；跨书集中整理，模式共享位置 |
| 容量 | 固定沿用10/32MiB、2000项 | 限额配置化；50/200MiB、5000项为待测候选，配合流式/分批/隔离/预算，不先改大常量 |
| 版权 | 四授权分离和旧来源补审 | 保留，补角色与贡献授权、受限引文页、撤回与历史审计、PDF原件交付边界 |
| 验收 | 四格式及R1—R5整体 | M1接入、M2阅读、M3整理引用、M4协作治理独立验收；增加真实排版矩阵，不把外部图示当样本 |

## 受影响的数据模型

1. `source_reading_editions`：增加layoutMode、模式/能力、覆盖/质量结果、独立readingVersionNo和supersedes关系；预览型版本不强制伪造成功parseRun。
2. 第一版`source_reading_chapters`改通用`source_reading_units`，增加unitType、顺序、布局、处理结果和单元能力；块改绑unitId。
3. `source_reading_toc_nodes`独立导航，可多个节点指向同一单元锚点或不提供目录；目录顺序与正文顺序分开。
4. 增加处理阶段/结果模型、原件/转换DOCX/PDF/预览/媒体的产物关系；保留原hash、父产物、转换器版本和安全状态。
5. 资产记录不局限PNG/JPEG输入，区分原格式与安全展示格式，保留失败位置/图注/帧范围；不向浏览器交付主动SVG。
6. 进度和摘录绑定unit/mode/readingVersion；精确文字引用仍须可靠文字位置，页面区域不能冒充文字精确定位。
7. 来源审核记录批准使用类型、coverageSnapshotHash、已确认警告和可引用范围；授权撤回独立记录事件，不编辑冻结历史。

数据库实际仍为V10；第一版V11草案未执行，需统一修订后才可应用。`document_segments`、原解析批次、历史引文、正式知识版本和既有外键关系不删除。

## 受影响的API与内部处理协议

| 边界 | 第二版调整 | 兼容原则 |
|---|---|---|
| 来源概览/处理状态 | 分阶段结果、PARTIAL_SUCCESS、缺失范围与可单独重试阶段 | 旧状态不冒充完整成功；旧接口可保留，但新UI看明确内容结果 |
| 阅读入口 | layoutMode、技术可用模式与用户有效能力、units摘要和可选目录 | 第一版未发布的readerApi需要重对齐，不构成现网新API承诺 |
| 单元正文 | `/reader/units/:unitId?mode=`，代替把每页叫chapter | 既有/source片段锚点继续兼容，不重写旧位置 |
| 预览与原件 | 受控artifact预览与原件/Range分开；无交付许可时拒绝原PDF | 不能把禁下载解释成仅隐藏按钮 |
| 引文公开 | 用正式资源/版本/evidenceId返回有限引文 | 不允许docId+任意quote查询整书，也不返回整章/整页 |
| 摘录/草稿追加 | 本人跨书摘录列表、向当前/其他可编辑草稿幂等追加 | 不强制每次新建知识，不泄露他人私有稿 |
| 来源审核决定 | 警告确认、批准使用类型和覆盖快照 | 自审、领取/版本锁、来源/知识双审核沿现有规则 |
| 转换/解析控制 | 受限任务标识、原件流式拉取、分批产物清单、心跳/超时 | 不接受任意外部URL/文件路径，不向客户端交付存储密钥 |

正式contracts、DTO、数据库迁移和前端调用要在下一实施授权后成套定稿；本轮没有把设计API伪标为已上线。

## 仍需确认的新增决策

仅三个新决策；已确认的四授权原则、旧来源LEGACY_UNCONFIRMED、独立协作提案、同一Compose项目不重复确认。

| ID | 推荐项 | 另一选择及代价 |
|---|---|---|
| D2-01 | 安全预览资料可审核为REFERENCE_ONLY；无可靠文字则禁自动文字整理/RAG | 暂不允许预览型来源提交审核，只作私有资料；扫描资料可用范围较小 |
| D2-02 | 不交付原件的PDF只走服务端页面预览，未生成时等待/不可用 | 首阶段只私有阅读此类PDF，等预览器验收后开放；不能用原PDF直送替代 |
| D2-03 | 50MiB原件/200MiB解压/5000项作为受控测试配置，测后确定默认值 | 先保持10/32MiB再逐档提高；无论选择哪种都保留炸弹/内存/超时限制 |

本轮交付到第二版设计和证据记录为止。用户后续确认决策不自动等同于现在恢复全部实施，仍按新的明确实施范围从M1开始。

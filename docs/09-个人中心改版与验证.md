# 个人中心改版与验证

日期：2026-11-18。依据用户确认的《个人中心改版设计方案》实施。

## 已实现

- 顶部个人名片：头像、昵称、简介、加入日期、学习者/贡献者标签，以及真实获赞、关注和粉丝数量。
- 主内容区：收藏、浏览历史、发表、点赞，获赞内容及关注/粉丝列表。支持搜索、分类、状态筛选、分页和 URL 状态恢复。
- 收藏和点赞可取消并短时撤销；历史可删除单条或确认清空。不可见内容保留安全占位，不返回其正文、摘要和私有版本。
- 独立资料设置页，保留原有昵称/简介保存，增加头像上传和未保存修改提示。
- 最小用户公开主页及资源正文详情。关注关系真实持久化，关注、取消关注和互动操作幂等。
- 文章草稿的创建、保存、提交审核、撤回、创建新修订和删除草稿。已提交版本保持不可变，修订和公开版本分开显示。
- 本人帖子可查看私有详情与状态；本轮不新增发帖编辑器及帖子管理流程。
- 桌面主辅栏布局、窄屏单列、键盘标签切换、可见焦点、44px 操作目标和减少动态效果支持。

## 数据与可见性

新增 Flyway `V4__user_follows.sql`，保留 V1/V2/V3 的迁移历史。运行中业务库共 70 张业务表；原始设计模型仍描述 V1 基线，新增关系以 V4 为准。

获赞只汇总本人公开文章/帖子收到的有效赞，排除本人点赞和禁用账户。修订不重复计数。关注与粉丝统一排除禁用账户；关系恢复随账户状态统一生效。

公开主页仅返回面向学习者的身份信息，不返回登录用户名、后台角色/权限、个人收藏、浏览历史、私有点赞、草稿或审核意见。当前公开主页仍要求登录，与平台现有鉴权范围一致。

知识内容的来源名来自正式版本关联的已审核、可用来源资料，与作者昵称区分。本人下架内容的状态说明来自真实 `suspended_reason`。

统计、列表、申请资格分别处理加载和失败；接口失败不伪装成统计为 0。文章编辑和公开主页写操作在路由切换或卸载后使旧回调失效。

## 头像存储

只接受实际可解码的 PNG/JPEG，最大 2MB、边长最多 2048 像素、总像素最多 400 万。服务端重新编码为 PNG，使用生成的 UUID 文件名；上传文件名与原始元数据不作为存储内容。

头像读取使用已鉴权 API，前端取得 Blob 后显示并及时释放。替换操作锁定本人记录，在事务提交后删除不再使用的旧文件，回滚时删除新文件，避免反复更换头像产生孤立文件。清理只处理合法的自有存储键。

本地开发脚本设置 `AVATAR_STORAGE_DIR` 为项目的 `runtime/avatars`，重启应用保留头像。其他部署环境应将此变量指向持久存储目录；本实现为单机文件存储，不宣称已实现对象存储或多实例文件共享。

## 审查中发现并解决的问题

1. Windows/JVM 系统时区使 JDBC Timestamp 转换发生 8 小时偏移：用 JDBC `LocalDateTime` 读取数据库 UTC 字段后显式转 UTC，增加实际数据库时间相等断言。
2. 公开资料最初透传后台角色：过滤为学习者可见标签，并验证不会泄露管理角色。
3. 获赞列表最初按时间排序：改为有效赞数降序，并以时间和资源 ID 稳定排序。
4. 公开主页列表请求失败最初使名片消失：分离资料和列表请求，列表可独立重试。
5. 文章保存的迟到响应可能覆盖刚打开的另一篇文章：增加页面操作版本和路由失效检查；组件回归用延迟真实交互复现后验证修复。
6. 更换头像最初遗留旧文件：增加事务清理，并通过回滚、并发替换与任意路径保护测试。
7. 真实 HTTP 超大图片上传在进入控制器前失败：配置 multipart 限制并针对上传异常返回统一校验错误；不只依赖 MockMvc 验证。

## 仍属于后续业务模块的内容

- 学习专题、学习进度与测验仍按原平台开放计划推进；个人中心显示真实的未开放说明。
- 提交文章会创建待处理审核任务，本轮没有新增社区内容审核台，也不自动通过审核或直接公开用户稿件。
- 正文以安全文本展示，保留 Markdown 原文，不执行正文 HTML。
- 私有问答回答收藏仍由原有独立数据模型承接，未混入资源收藏。

既有登录、密码、会话相关未提交工作保持在工作区；本轮没有提交、合并或推送代码。

# 功能与数据库映射

95项功能全部提供模型承载点。本表是设计承载映射，不是“95项均已完成”的清单；实际交付范围以第一阶段、个人中心和第二阶段验收文档为准。文件数量与表数量不代表业务完成量。纯算法、Redis限流和SSE协议不需要各建一张表。

第二阶段的实际状态见 [第二阶段实现与验收](10-第二阶段实现与验收.md)：K01–K04 来源与解析、K07–K14 草稿/证据/审核/版本/停用主流程，以及 Z01–Z09、Z13–Z14 的知识浏览、追溯、对比与互动已接入。K05 目前是人工确认的片段转草稿；K06 为人工规范名/别名维护，不宣称自动术语识别。K15 仅产生可观察的索引任务，执行在第四阶段。管理数量来自真实列表分页和状态查询，不宣称已有独立跨域统计仪表盘；Z10–Z12 的方剂识别/学习解读和 Z15 的学习/社区关联入口按后续阶段继续实现。

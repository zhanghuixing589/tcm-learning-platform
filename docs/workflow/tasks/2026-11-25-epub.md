## 范围与方案

既有上传→来源→异步解析→片段预览→人工审核链新增未加密文本EPUB；不转换PDF、不渲染电子书阅读器、不增加OCR、模型服务、数据库迁移或权限。只用现有Java ZIP/XML与Python zipfile/defusedxml，无依赖锁变更。

1. SourceFiles交给EpubFiles做实际包结构和有界ZIP/XML校验，保存application/epub+zip；继续SHA256去重、每上传者授权和原下载权限。
2. Python documents分派epub.epub_segments，读取container→OPF manifest/spine→XHTML，按阅读顺序提取纯文本。headingPath保留书名/章节标题，pageLabel保留章节/段落位置，不伪造纸书页码。不自动用OPF元数据覆盖来源表单，人工填写的书目信息仍需校对。
3. 保留原10MB上传、32MB解压、200倍压缩比、2000 ZIP项、200万文本字符和1万片段限制。拒绝加密描述、ZIP重复项、越界路径、非本地章节引用及实体；允许普通DOCTYPE但不加载外部DTD。脚本、样式、嵌入对象、导航不作为正文；图像型无正文书解析失败。
4. 前端SourceView扩展accept、验证和提示；页面原片段预览无需新类型。契约/索引/模块同步，无新测试选择依赖；新增测试由全Java/AI规则自动发现。

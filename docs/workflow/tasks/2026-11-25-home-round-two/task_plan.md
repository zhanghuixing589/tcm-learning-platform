# 首页第二轮 UI/UX 优化

## 边界与方案
- 保留现有设计、导航、植物插画和主标题，只修改 HomeView.vue、HomeContent.vue、home.css 及首页验证。
- 搜索复用 /knowledge?q=；学习入口使用现有类型筛选。用户已确认采用中医概念入口。

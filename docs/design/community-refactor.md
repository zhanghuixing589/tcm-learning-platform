# 社区专项重构：从内容列表到交流空间

日期：2026-11-24。基于本轮用户授权直接实施，不改后端契约。此前全站样式与分页修改保留；本次开始时的相关前端快照在忽略目录 `runtime/community-ui-baseline/`。

## 定位与参考

知识中心沉淀专业审核后的正式知识；社区容纳用户分享、讨论与投稿。社区首页以“发现—参与—继续交流”为路径，不能以知识可信标签代替社区作者、分区和互动信息。

[少数派](https://sspai.com/) 公开页可读取：栏目、内容切换、作者/时间、文章与讨论并置、侧栏内容，借鉴信息组织而不复制其品牌或付费内容。[知乎](https://www.zhihu.com/) 本次访问403，仅依据用户给定的内容发现/话题组织方向设计，不声称已实际浏览受限页面。沿用全站 [参考调研](reference-analysis.md) 的Editorial与SaaS取舍，不重复制定一套品牌。

## 现有能力与页面映射

| 现有业务/依据 | 本次页面/组件 | 保留边界 |
|---|---|---|
| `sectionTree()`，后台两级分区/成员/权限 | 首页与分区页左栏 SectionNavigation，右栏真实分区速览 | 全部来自API，不硬编码中药天地等替换真实分类；我的分区继续按成员状态过滤 |
| `/posts`：ALL/ARTICLE/POST，NEWEST/LATEST_REPLY，q/sectionId/page | PostFeed、独立内容卡与紧凑工具栏 | 只启用最新/最近回复；无热门/推荐/关注算法，不伪装这些栏目 |
| Post.owner/summary/publishedAt/互动计数 | 信息流文章/讨论差异、当前列表作者 | 无封面/标签/学习笔记字段：不发明字段、不提取外链封面，使用明确类型默认视觉 |
| `/posts/{id}`，Markdown政策，版本与文献 | CommunityReader、正文目录、作者栏、同区延伸阅读 | 正文仍按既有白名单清洗；目录来自实际渲染标题；普通文本不解析为Markdown；图片仍遵循现有政策，不擅自开放外链图片 |
| resource like/bookmark，CommentThread版本/分页/回复 | 互动操作、评论锚点、讨论阅读区 | 原授权、幂等、并发锁、隐藏与冲突处理不变 |
| 文章ArticleInput/ArticleAction | ArticleEditorView + 公共发布导航/写作指引 | 保存草稿→提交审核，撤回/修订/额度/文献功能保留 |
| PostCreate/PostEdit，讨论直接发布 | DiscussionEditorView + 同一发布视觉体系 | 无讨论草稿接口，不显示“保存草稿”；修改说明/历史/未保存离开保护保留 |
| 无公告/热门话题/作者推荐接口 | 右栏参与提示、真实分区、当前页作者 | 提示是静态界面帮助，不假冒动态公告；局部数据说明范围，无虚构统计与权威排名 |

## 布局方案

- 桌面三栏约176px / minmax(0,1fr) / 240px，主列优先。页头置于中间列：社区简介、发布入口、类型切换、搜索与排序；左栏保持轻导航，右栏提供参与理由与真实内容线索。
- 文章采用横向图文编排，统一比例的文稿默认图作为无封面状态；讨论采用更紧凑的交流卡与评论入口，所有互动数来自记录。
- 详情区使用舒适的阅读纸面、作者身份、真实目录、互动工具与评论；讨论减少展示性留白、突出参与讨论锚点。同区阅读只调用既有列表并排除当前资源，不宣称语义推荐。
- 发布页共用内容类型导航与双栏写作工作区：主要表单/预览在左，发布链路与写作提示在右。类型切换仅新建时可用，原离开保护生效。
- 1024–1279优先主列，右栏移至下方；平板收缩目录；手机紧凑分区、纵向信息流、右栏下移，正文目录可折叠。复用全站tokens，不改知识中心布局。
